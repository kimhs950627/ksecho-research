# segment_map.py — 벽운동 eyeball 보조 프로토타입

ED/ES 심내막 경계에서 **구역별 내향 변위 지수**를 계산해 6구역 지도로 내는 스크립트.
딥러닝 없이 기하 계산만으로 동작하며, 데모 모드가 내장되어 있어 데이터 없이도 오늘 실행할 수 있다.

## 실행

```bash
# 1) 데이터 없이 바로 (합성 저운동 구역 주입)
python3 segment_map.py --demo
python3 segment_map.py --demo --impaired basal_lateral

# 2) CAMUS 실데이터로
python3 segment_map.py --camus-dir /path/to/camus/training --case patient0001
```

출력:

```
구역                  지수       z  판정
기저 중격            0.111   -1.08  정상
중간 중격            0.040   -3.20  주의      ← 주입한 구역
첨부 중격            0.208   +1.52  정상
...
주의 구역 1개: 중간 중격
저장: out/demo_map.png · demo_segments.csv
```

## 의존성

- 필수: `numpy`, `matplotlib`
- CAMUS 실행 시: `SimpleITK`

## 계산 순서

1. **마스크에서 중심** — ED 심내막 마스크의 무게중심
2. **r(θ)** — 중심에서 방사 방향으로 나가며 마지막으로 마스크에 닿는 거리 (240방향)
3. **심첨축** — r이 최대인 방향. 실제 좌심실은 기저가 판막면으로 잘려 있어 이 규칙이 안정적
4. **φ** — 심첨 기준 부호 있는 각도. |φ| 3분할 = 첨부·중간·기저, 부호 = 중격·측벽
5. **지수** — `(r_ED − r_ES) / LV길이` 의 구역 평균
6. **z** — 정상 분포 대비 표준화. `z ≤ −2` 를 '주의'로 표시

LV 길이로 나누는 이유는 심장 크기가 달라도 비교가 되게 하기 위해서다.

## 데모가 검증하는 것

합성 ED/ES 쌍에 한 구역만 수축률을 4%로 낮추고(나머지 22%) 주입한 뒤, 스크립트가 그 구역을
정확히 지목하는지 확인한다. 두 가지 주입 모두 맞혔고, 나머지 다섯 구역은 정상 범위에 남았다.
이것이 코드의 자체 회귀 검사 역할을 한다.

| 주입 | 검출 | z |
|---|---|---|
| mid_septal | 중간 중격 | −3.20 |
| basal_lateral | 기저 측벽 | −3.15 |

## 하지 않는 것

- **벽운동을 진단하지 않는다.** 기하학적 대리지표(surrogate)만 계산한다.
- 2방·4방 두 뷰만 다룬다. 3방·단축·TEE는 범위 밖.
- 스펙클 잡음 보정이 없다. 광학흐름이 아니라 경계 반경만 쓴다.
- `DEMO_REFERENCE` 는 데모 상수다. **실제 연구 전에 정상 EF 코호트에서 계산한 값으로 반드시 교체**해야 한다.
